# حساباتي التجارية — نسخة أولية قابلة للتجربة

برنامج حسابات عربي RTL للموبايل، يعمل محليًا في المتصفح ويستخدم IndexedDB. البيانات المالية تبقى على جهازك ولا تُرفع إلى GitHub.

## الوظائف
- مخزون بالقيمة المالية فقط، دون أصناف أو كميات.
- تسجيل فواتير التوريد بتاريخها التاريخي، مع المورد وقيمة الفاتورة والمدفوع نقدًا وبالبنك والمتبقي.
- حساب ديون الموردين وكشف حساب زمني لكل مورد، مع سداد نقدي أو بنكي أو مزيج منهما.
- العملاء والأرصدة الافتتاحية، وتسجيل المبيعات القديمة بتاريخها وقيمتها وتكلفتها والتحصيل النقدي والبنكي والمتبقي.
- تسجيل تحصيلات العملاء اللاحقة بتقسيم النقد والبنك، وكشف حساب برصيد متحرك بعد كل معاملة.
- المصروفات والتقارير وتصدير/استعادة JSON.
- ترقية قاعدة البيانات المحلية تلقائيًا من الإصدار 1 إلى 3: إضافة سجل الموردين ثم مخزن مستقل لنسخ الأمان المحلية، مع الاحتفاظ بسجلات العملاء والمعاملات الحالية.

مع Node.js: `npm test` ثم `node --check src/app.js` و`node --check src/db.js` و`node --check src/ledger.js`.

## قواعد إدخال الأرصدة القديمة
1. أضف الموردين والعملاء أولًا.
2. أدخل كل فاتورة توريد قديمة بتاريخها وقيمتها الإجمالية، ثم المدفوع نقدًا والمدفوع بنكيًا. المتبقي يحسب تلقائيًا.
3. أدخل المبيعات القديمة بالتاريخ والقيمة وتكلفة البضاعة، مع توزيع التحصيل بين النقد والبنك.
4. أدخل التحصيلات والسدادات اللاحقة فقط إذا لم تكن مدرجة ضمن المدفوع في الفاتورة.
5. لا تسجل الدين نفسه في الرصيد الافتتاحي وفي الفواتير معًا. الرصيد الافتتاحي مخصص فقط للمبالغ التي لا تسجل تفاصيلها كمعاملات.
6. قد يظهر المخزون أو الرصيد مؤقتًا غير مكتمل أثناء إدخال السجلات التاريخية؛ راجع الإجماليات بعد إنهاء جميع الفواتير.

## حماية البيانات
- تغيير بنية قاعدة البيانات محليًا يضيف مخزن الموردين ولا يمسح مخازن العملاء والمعاملات.
- نسخ JSON تحتوي بيانات تجارية حساسة؛ لا ترفعها إلى المستودع أو تشاركها علنًا.
- عند استعادة نسخة قديمة من الإصدار 1، لا تحتوي على موردين؛ لذلك ستستبدل قائمة الموردين الحالية بقائمة فارغة. صدّر نسخة حديثة قبل أي استعادة.
- نسخ الأمان المحلية منفصلة عن بيانات النشاط، ويحتفظ التطبيق بآخر 3 نسخ على الجهاز. استعادة ملف أو نسخة سحابية تنشئ نسخة أمان محلية قبل الاستبدال.\n- النسخ السحابي عبر Firebase يحتفظ بآخر 5 نسخ مكتملة لكل حساب؛ النسخ غير المكتملة لا تظهر للاستعادة.\n- النسخ اليومي يعمل عند فتح التطبيق أو عودته للواجهة مع الإنترنت؛ لا يُضمن إنشاء نسخة جديدة إذا كان التطبيق مغلقًا بالكامل.\n- حفظ Google Drive يستخدم منتقي ملفات Android: اختر Google Drive كمكان للحفظ، ثم استخدم استعادة ملف لاختيار النسخة عند الحاجة.
