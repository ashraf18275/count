# حساباتي التجارية — نسخة أولية قابلة للتجربة

برنامج حسابات عربي باتجاه RTL، مصمم للموبايل، يعمل محليًا في المتصفح ويستخدم IndexedDB لحفظ البيانات على الجهاز. يدعم التثبيت كتطبيق ويب (PWA) والعمل دون إنترنت بعد تحميل الملفات مرة واحدة.

## الوظائف الحالية
- تسجيل الوارد بالقيمة المالية فقط، دون أصناف أو كميات.
- مخزون مالي يزيد بالوارد وينقص بتكلفة البضاعة المباعة.
- إضافة العملاء والأرصدة الافتتاحية.
- تسجيل المبيعات، المدفوع فورًا، والمتبقي على العميل.
- تسجيل التحصيلات اللاحقة، مع كشف حساب يعرض تفاصيل البيع والرصيد بعد كل معاملة.
- تسجيل المصروفات وتقارير أولية للمبيعات والمخزون والربح.
- تصدير نسخة احتياطية JSON واستعادتها بعد التأكيد.
- اختبارات حسابية عبر Node.js وGitHub Actions.

## تشغيل محلي أو في Codespaces
يتطلب Python 3. من مجلد المشروع شغّل:

```bash
python -m http.server 8000
```

افتح `http://localhost:8000`. في Codespaces افتح تبويب Ports وافتح المنفذ 8000. لا تفتح `index.html` مباشرة من نظام الملفات.

لتشغيل الاختبارات محليًا مع Node.js:

```bash
npm test
node --check src/app.js
node --check src/db.js
node --check src/ledger.js
```

## قواعد محاسبية
- تحفظ المبالغ كقروش صحيحة لتجنب أخطاء الكسور العشرية.
- الربح المسجل = المبيعات - تكلفة البضاعة المباعة - المصروفات.
- المخزون مالي فقط وليس إدارة أصناف وكميات. يجب إدخال تكلفة الجزء المباع عند كل عملية.
- الرصيد الموجب للعميل يعني أنه مدين لك؛ الرصيد السالب يعني أن له رصيدًا لديك.
- التحصيل اللاحق لا يُسجّل كبيع جديد، بل يقلل رصيد العميل.

## حدود مهمة
- المزامنة السحابية غير مفعّلة حتى الآن؛ البيانات محلية لهذا المتصفح/الجهاز فقط.
- هذه نسخة أولية ولم تُعتمد بعد كدفتر الحسابات الوحيد. اختبر التشغيل والتصدير والاستعادة واحتفظ بنسخ احتياطية خارج الجهاز قبل إدخال بيانات تجارية مهمة.
- لا تُرفع نسخ البيانات الاحتياطية إلى GitHub؛ فهي تحتوي بيانات مالية حساسة.
