# حساباتي التجارية — نسخة أولية قابلة للتجربة

برنامج حسابات عربي باتجاه RTL، مصمم للموبايل، يعمل محليًا في المتصفح ويستخدم IndexedDB لحفظ البيانات على الجهاز. يدعم التثبيت كتطبيق ويب (PWA) والعمل دون إنترنت بعد تحميل الملفات مرة واحدة.

## الوظائف الحالية
- تسجيل الوارد بالقيمة المالية فقط، دون أصناف أو كميات.
- مخزون مالي يزيد بالوارد وينقص بتكلفة البضاعة المباعة.
- إضافة العملاء والأرصدة الافتتاحية.
- تسجيل المبيعات، المدفوع فورًا، والمتبقي على العميل.
- تسجيل التحصيلات اللاحقة، مع كشف حساب يعرض تفاصيل البيع والرصيد بعد كل معاملة.
- تسجيل المصروفات وتقارير أولية للمبيعات والمخزون والربح.
- تصدير نسخة احتياطية JSON واستعادتها بعد التأكيد.
- اختبارات حسابية عبر Node.js وGitHub Actions.
- نشر تلقائي للواجهة الثابتة عبر GitHub Pages عند تحديث الفرع `main`.

## فتح التطبيق
بعد نجاح سير عمل **Deploy accounting app to GitHub Pages**، افتح:
https://ashraf18275.github.io/count/

قد يستغرق النشر الأول بضع دقائق. إذا لم يعمل الرابط بعد أول تشغيل، راجع تبويب Actions وتأكد من نجاح سير عمل النشر.

## تثبيت التطبيق على الموبايل
1. افتح رابط التطبيق في Chrome.
2. من قائمة المتصفح اختر **إضافة إلى الشاشة الرئيسية** أو **Install app** إن ظهر الخيار.
3. افتح التطبيق من الأيقونة. افتحه مرة واحدة أثناء الاتصال حتى تُحمّل ملفات العمل دون إنترنت.

## تشغيل محلي أو في Codespaces
يتطلب Python 3. من مجلد المشروع شغّل:

```bash
python -m http.server 8000
```

افتح `http://localhost:8000`. في Codespaces افتح تبويب Ports وافتح المنفذ 8000. لا تفتح `index.html` مباشرة من نظام الملفات.

لتشغيل الاختبارات محليًا مع Node.js:

```bash
npm test
node --check src/app.js
node --check src/db.js
node --check src/ledger.js
```

## قواعد محاسبية
- تحفظ المبالغ كقروش صحيحة لتجنب أخطاء الكسور العشرية.
- الربح المسجل = المبيعات - تكلفة البضاعة المباعة - المصروفات.
- المخزون مالي فقط وليس إدارة أصناف وكميات. يجب إدخال تكلفة الجزء المباع عند كل عملية.
- الرصيد الموجب للعميل يعني أنه مدين لك؛ الرصيد السالب يعني أن له رصيدًا لديك.
- التحصيل اللاحق لا يُسجّل كبيع جديد، بل يقلل رصيد العميل.

## الخصوصية والنسخ الاحتياطي — مهم
- كود التطبيق عام، لكن بيانات الحسابات لا تُرسل إلى GitHub أو إلى خادم؛ تُحفظ محليًا في متصفح الجهاز باستخدام IndexedDB.
- لا تُدخل بيانات مالية حقيقية إلا بعد اختبار التطبيق والتأكد من النسخ الاحتياطي والاستعادة.
- لا ترفع نسخ البيانات الاحتياطية أو ملفات قواعد البيانات أو كلمات المرور أو مفاتيح الوصول إلى المستودع العام.
- حذف بيانات المتصفح أو فقدان الجهاز قد يؤدي إلى فقدان البيانات؛ صدّر نسخة JSON بانتظام واحفظها في مكان آمن خارج المستودع.
- لا توجد مزامنة سحابية بين الأجهزة في النسخة الحالية.
- هذه نسخة أولية، ولا يُنصح باعتمادها كدفتر الحسابات الوحيد لنشاط تجاري قبل إتمام الاختبار العملي.

## الاختبارات
تُشغّل اختبارات الحسابات وفحص صياغة JavaScript تلقائيًا مع GitHub Actions عند الدفع إلى `main` أو فتح Pull Request.
